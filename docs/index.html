model-census 0.2.0

Which AI models does your code reference, and whose weights are they built on? Paste code or config, or trace a Hugging Face model's declared lineage. Distilled and fine-tuned derivatives count, so deepseek-r1-distill-llama-70b shows up as DeepSeek + Meta. The CLI does the same for a whole repo: npx github:thinx-pro/model-census.

Runs locally in this page. Nothing is uploaded.

Sends the model ids to the public Hugging Face API (huggingface.co) from your browser. Lineage is what uploaders declared in base_model; the tokenizer check looks for DeepSeek's special tokens, which survive renaming.

Static scan of references, not proof of runtime traffic. Unknown ids are not counted. Source, CLI, CycloneDX 1.6 output and limitations: github.com/thinx-pro/model-census · MIT
